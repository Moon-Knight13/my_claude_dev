
## Active Mode: dev

General software development. Full coding toolchain, no offensive tools.
No engagement active. No OPSEC rules apply.

### What this mode is for
- Application development (any language, any framework)
- Library and package development
- API design and implementation
- Database design and migrations
- Testing, debugging, refactoring
- CI/CD pipeline configuration
- Documentation and technical writing
- Open source contribution

### What this mode is NOT for
- Any offensive operation (use red-team)
- Exploit development or RE (use red-dev)
- Range infrastructure deployment (use green-dev)
- Framework/harness development (use platform-ops)
- CTF challenges (use ctf)
- Penetration testing (use pentest)
- Bug bounty hunting (use bounty)

### Available tools
- local-ollama (code assistance)
- All standard development tools (git, npm, docker, bash)

### Skill Filter for dev mode
Preferred skills: bmad-*, superpowers:*.
Do NOT invoke offensive or engagement skills unless operator explicitly requests them.
